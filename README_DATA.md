# NovaBank — Synthetic Banking Data

## AI-Powered Banking Customer Query Assistant

This directory contains **synthetic banking datasets** for the AI-Powered Banking Customer Query Assistant project. All data is completely fictional and generated for **NovaBank**, a fictional Indian bank.

> ⚠️ **No real customer information is used.** All names, account numbers, PAN, Aadhaar, phone numbers, email addresses, and financial records are entirely synthetic.

---

## Directory Structure

```
data/
├── customers.json            # 10 synthetic NovaBank customers
├── accounts.json             # 15-20 bank accounts (Savings/Current/Salary)
├── transactions.json         # ~1500 synthetic transactions (last 12 months)
├── loans.json                # 12 loan products (Home/Personal/Education/Vehicle)
├── products.json             # NovaBank product catalog (accounts, FDs, credit cards, loans)
├── customer_profiles.json    # Customer preferences, segments, consent flags
├── customer_query_logs.txt   # 200+ simulated customer queries (TEXT format)
├── query_labels.json         # Intent labels for each query
└── processed_queries.json    # Tokenized and labeled queries (generated by preprocessor)

scripts/
├── generate_data.py          # Generates all synthetic datasets
├── preprocess_queries.py     # Tokenizes queries and associates intent labels
└── validate_data.py          # Validates referential integrity and completeness
```

---

## Quick Start

### 1. Generate all datasets

```bash
python scripts/generate_data.py
```

### 2. Preprocess queries (tokenization + intent labeling)

```bash
python scripts/preprocess_queries.py
```

### 3. Validate data integrity

```bash
python scripts/validate_data.py
```

## Dataset Details

### customers.json

| Field | Type | Description |
|-------|------|-------------|
| customer_id | string | Unique ID (CUST001–CUST010) |
| name | string | Fictional Indian name |
| age | int | Customer age |
| gender | string | Male/Female |
| city | string | Indian city |
| occupation | string | Job title |
| monthly_income | int | Monthly income in INR |
| credit_score | int | Credit score (600–810) |
| consent | bool | Consent for data processing |

### accounts.json

| Field | Type | Description |
|-------|------|-------------|
| account_id | string | Unique ID (ACC001–ACC0XX) |
| customer_id | string | References customers.json |
| account_type | string | Savings / Current / Salary |
| balance | float | Current balance in INR |
| currency | string | Always "INR" |
| status | string | Active / Dormant |
| opened_date | string | Account opening date (YYYY-MM-DD) |

### transactions.json

| Field | Type | Description |
|-------|------|-------------|
| transaction_id | string | Unique ID (TXN00001–TXN01500) |
| customer_id | string | References customers.json |
| account_id | string | References accounts.json |
| date | string | Transaction date (YYYY-MM-DD) |
| type | string | CREDIT / DEBIT |
| amount | float | Amount in INR |
| merchant | string | Synthetic merchant name |
| category | string | Food, Shopping, Travel, etc. |
| description | string | Transaction description |
| status | string | SUCCESS / PENDING / FAILED |

### loans.json

| Field | Type | Description |
|-------|------|-------------|
| loan_id | string | Unique ID (LOAN001–LOAN012) |
| loan_name | string | Product name |
| loan_type | string | Home / Personal / Education / Vehicle |
| minimum_amount | int | Min loan amount in INR |
| maximum_amount | int | Max loan amount in INR |
| interest_rate | float | Annual interest rate (%) |
| minimum_income | int | Required monthly income in INR |
| minimum_credit_score | int | Required credit score |
| minimum_age | int | Min borrower age |
| maximum_age | int | Max borrower age |
| maximum_tenure_years | int | Max loan tenure in years |
| processing_fee_percent | float | Processing fee (%) |
| required_documents | array | List of required documents |

### products.json

Banking product catalog including Savings Accounts, Current Accounts, Fixed Deposits, Credit Cards, and Loan summaries.

### customer_profiles.json

| Field | Type | Description |
|-------|------|-------------|
| customer_id | string | References customers.json |
| preferred_language | string | Regional language preference |
| communication_preference | string | Email / SMS / WhatsApp / Phone Call |
| customer_segment | string | Standard / Premium / Gold / Platinum |
| employment_type | string | Salaried / Self-Employed / Student / Retired |
| relationship_years | int | Years with NovaBank |
| consent_for_personalization | bool | Personalization consent flag |

### customer_query_logs.txt

Plain text file with simulated customer queries:

```
2026-09-01 09:15:21 | customer=CUST001 | What is my current account balance?
2026-09-01 09:16:04 | customer=CUST002 | Can you show me my last five transactions?
```

### query_labels.json

Intent labels for every query in the log file:

```json
{
  "query_id": "Q001",
  "intent": "CHECK_BALANCE",
  "expected_agent": "BANKING_AGENT",
  "expected_data_source": "ACCOUNTS"
}
```

### processed_queries.json

Tokenized and labeled version of each query:

```json
{
  "query_id": "Q001",
  "customer_id": "CUST001",
  "query": "What is my current account balance?",
  "tokens": ["what", "is", "my", "current", "account", "balance"],
  "intent": "CHECK_BALANCE"
}
```

## Currency

All monetary values are in **Indian Rupees (INR)**.

---

## Privacy & Compliance

- All data is **100% synthetic** — no real individuals are represented
- Privacy masking is applied: no real PAN, Aadhaar, phone numbers, or emails
- Customer consent flags are included for data-processing compliance
- Personalization consent is tracked separately in customer profiles

---

## Reproducibility

The data generation script uses a **deterministic random seed** (`SEED = 42`), so re-running `generate_data.py` produces identical datasets.
